# ghidra-barbados
Barbados: tools written in Python for Ghidra. Generate AOB (Array of Bytes) that work across binary.

## Usage
1. Clone this repo.
2. Add the repo folder as a Ghidra script location. To do this, navigate to the Script Manager and add the folder from there.
3. Scripts can now be run from Ghidra. Most scripts have default behavior when run. Most scripts can also be imported from the Python REPL Ghidra provides.
